## No-Overlap Validation Configuration

The validation cards use the diagnostic contract in
[`PHYSICS-CONTRACT.md`](PHYSICS-CONTRACT.md):

```text
heavy_quark_eloss_mode = 2
heavy_quark_lambda = 1.961
heavy_quark_charm_mass = 1.25
heavy_quark_bottom_mass = 4.2
heavy_quark_add_generic_broadening_with_diffusion = false
heavy_quark_enable_hard_moliere = false
```

An additional one-event compatibility run enables additive generic broadening
to retain coverage of the first MMLHI behavior. Dedicated diagnostic-only
runs separately enable hard charm Moliere.

This is not a completed soft-matching prescription. Mode-2 heavy diffusion is
applied only when the heavy-drag branch wins. With generic broadening disabled,
baseline-winning steps have no stochastic soft kick. With compatibility mode
enabled, drag-winning steps receive both generic and heavy diffusion. The
production choice between those limits remains open.

### Independent rerun and implementation cross-review

The full runner was repeated from MMLHI `bbe19cc` against parent MMLI
`5f12976`, using the pinned PYTHIA 8.315 library. It passed with clean tracked
states; exact provenance is stored in `results/20260720-provenance.txt`. The
fresh artifacts are under
`/raid5/data/yjlee/hybrid_dev/test/mmhli_validation_modee_dani_20260720`.

This exact closure is a software statement: it proves that the heavy-off child
does not perturb the sampled parent paths. It does not validate inherited MMLI
physics approximations. The source and ROOT-record review found these boundaries:

- Mode D probes leave momentum/recoil/hole state untouched, but they advance
  copied RNG state in fixed daughter order. Only Mode E has branch-local,
  traversal-order-independent probe streams.
- Mode E daughter materialization preserves total energy, not full spatial
  momentum. The heavy-mode-off resolving test has average/max opening residuals
  of `0.750/7.716 GeV`; its maximum relative residual is `0.320`.
- The feature-on 20-event Mode-E run has 23 openings with average/max spatial
  residuals `0.193/1.856 GeV` and maximum relative residual `0.222`. Its C/D/E
  runs have zero unresolved elastic candidates, so heavy-on resolving-scatter
  behavior remains unexercised.
- The opening helper materializes massless daughters. In a seed-`870001` ROOT
  audit, an anti-charm daughter remains massless from `t=6.166` to
  `7.166 fm/c`; the first in-medium heavy update imposes the `1.25 GeV` floor
  and changes lab energy `48.768 -> 51.351 GeV`. This is an implementation gap,
  not physical energy gain. The exact transition is recorded in
  [`results/20260720-modee-heavy-mass-shell-audit.tsv`](results/20260720-modee-heavy-mass-shell-audit.tsv).
- `LundGenerator` keeps transport three-momentum but reconstructs energy with
  PYTHIA's particle-data mass. With PYTHIA 8.315, direct charm/bottom normally
  use `m0=1.50/4.80 GeV`; the configured `1.25/4.2 GeV` values are only lower
  transport floors.

## Controlled Legacy Comparison

The clean legacy worktree was patched only in scratch space to use the MMLHI
`mt19937_64` transport generator and to disable wake RNG consumption. PYTHIA
8.315 hard records, event metadata, hydro, production points, and seeds are
identical. Mode 1 uses `kappa=0` and no Moliere scattering.

At `|eta| < 1`, 20 events contain 11 matched final heavy quarks per flavor:

| Metric | Charm | Bottom |
|---|---:|---:|
| Mean MMLHI-minus-legacy `pT` fraction | +2.59% | +1.12% |
| RMS fractional `pT` difference | 3.64% | 1.58% |
| Maximum absolute fractional `pT` difference | 7.05% | 4.14% |
| Mean fractional energy difference | +1.83% | +0.45% |
| Maximum direction difference | 0.0447 rad | 0.0133 rad |

The exact metrics are in the `20260720-legacy-*-eta1.tsv` files. The residual
difference is expected from exact on-shell reconstruction versus the legacy

at approximately `|eta|=7`: the legacy finite-eta hydro leaves it outside the
medium while the MMLI 2+1D lookup is boost-invariant. That is a hydro-contract
difference, not a heavy-kernel comparison.

### Diffusion Is Not A Same-Seed Trajectory Test

Mode 2 was also run with fixed `x=y=0` so diffusion RNG use could not move the
next event's production point. The resulting event-by-event differences are
large: 86% fractional-`pT` RMS for charm and 32% for bottom in only seven
matched midrapidity quarks. This does not by itself show different diffusion
physics. The legacy Box-Muller draw uses `sin(2*pi*u)`, while MMLHI uses
`cos(2*pi*u)`; both are Gaussian with the same variance but produce different
same-seed kicks. Once the first kick differs, later paths and cell histories
also differ.

The enforceable software contract is therefore statistical. The unit test
resets the same incoming quark for 50,000 Mode-3 draws and requires each
Cartesian kick to have zero mean and variance
`pi*sqrt(lambda)*gamma*T^3*dt_star/0.2` within 3%. A sufficient-statistics spectrum
comparison remains required.

## Hard Charm Audit

The existing hard sampler constructs its incoming table projectile with
`E=|p|`, even for charm. The diagnostic checks each accepted scattering before
later broadening or continuous loss:

```text
m_out^2 = max(m_charm^2, m_in^2)
p_projectile + p_thermal = p_projectile_after + p_recoil
```

In the 100-event direct Moliere audit, all seven accepted hard charm scatters
fail both checks. The maximum mass-squared residual is 2.25 GeV^2 and the
maximum Euclidean four-vector closure norm is 0.447 GeV. The separate
100-event Mode-E diagnostic run finds ten hard charm records; all ten fail both
checks. This is a characterized implementation gap, not an acceptable physics
mode.

Simply projecting the outgoing charm onto a massive shell would not repair the
sampled rate, angular distribution, or recoil kinematics. The recommended
configuration therefore disables hard charm. Light-parton Moliere remains
enabled; bottom remains continuous-only.

## Hadronization Caveat

The validation target is parton transport. PYTHIA retried one hadronization in
the 100-event direct-Moliere sample and succeeded. The 20-event Mode-E sample
contains one `forceHadronLevel` give-up, repeated deterministically in its
exact rerun. Event blocks remain complete, but this is not a hadron-level
validation and the summary records retries and give-ups explicitly.

There is also a kinematic contract gap before any retry: `LundGenerator`
rebuilds each appended parton's energy from its transported three-momentum and
PYTHIA `m0`. It does not preserve the transport four-vector. This is benign
only when the transported parton is already on the same mass shell. The Mode-E
heavy boundary described above violates that premise.
