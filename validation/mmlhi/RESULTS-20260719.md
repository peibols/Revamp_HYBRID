## Heavy Flavor With Moliere Enabled

The implemented order within an in-medium integration step is:

1. sample and apply an eligible hard Moliere scattering;
2. apply the existing generic soft transverse kick when `kappa != 0`;
3. apply the heavy drag/diffusion kernel for a charm or bottom object;
4. use the ordinary light-HYBRID candidate instead when it wins the heavy
   crossover test.

Hard sampling currently accepts gluons and quarks through charm, but not
bottom. A charm hard scatter is identified by flavor matching; recoil and hole
objects are produced once, and a charm recoiler receives continuous heavy
transport if it propagates again. Holes are stored without rescattering.

With finite LRES, heavy transport follows the object chosen by the LRES mode.
For example, an unresolved gluon parent of a `g -> c cbar` splitting receives
light/coherent transport in Mode A, while Mode B propagates the charm daughters
separately and applies the heavy kernel to each. Modes C-E interpolate through
their respective candidate and coherence algorithms. The LRES timeline itself
is unchanged by this branch.

## Physics Assessment

The implementation is coherent as a software composition, but it is not yet a
validated heavy-flavor physics prescription:

- Combining rare hard scattering with a separately matched soft sector can
  make physical sense. It requires an explicit momentum-transfer separation
  and a joint tune.
- Here the generic `kappa` broadening and the new heavy diffusion are both
  active and additive. Both represent soft momentum broadening, so using both
  without a matching or subtraction prescription can double count diffusion.
- The hard charm path uses the existing Moliere table and flavor-matching
  machinery, whose propagation kinematics treat the incoming scattering
  four-vector as massless. A subsequently selected heavy update reconstructs
  the configured mass shell, but a baseline-selected step follows the legacy
  path. A dedicated end-to-end massive-scattering validation is required.
- Bottom receives drag/diffusion but no hard Moliere scattering. Requesting
  Moliere therefore changes the hadronization path selection but did not change
  the bottom parton output in the one-event smoke.
- The choice of which unresolved effective object carries heavy identity is
  mode dependent and can materially change the amount of heavy transport.
  That is a physics choice, not merely an implementation detail.
- Heavy coalescence/recombination is absent, so no D- or B-hadron `R_AA` or
  `v2` claim follows from these tests.

Before production, decide the soft-broadening matching, validate massive charm
hard scattering, decide whether bottom needs hard tables, and integrate the
intended heavy-hadron formation model.
